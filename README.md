[City Finder ]
Overview
City Finder is a web application that allows users to search for hotels or hospitals in any city. It displays the original location, ratings, and user comments for each place.
Features
Search for hotels and hospitals by city.
Display location on a map.
Show ratings and user comments for each result.
Simple, login-free experience.
Tech Stack
Frontend: React
Backend: Node.js
Database: MongoDB
APIs: Google Maps API for location services.

Installation:
(1) Clone the repository:
git clone

(2) Install dependencies:
cd
npm install

(3) Run the web:
npm start

Future Improvements
User login and authentication system.
Personalized user accounts.
Additional filters for searches (e.g., price, distance).
